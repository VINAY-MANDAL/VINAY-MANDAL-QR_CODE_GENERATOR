# QR Code Generator (Python + Tkinter)

A simple **QR Code Generator desktop application** built with **Python**.
This project allows users to convert **text, numbers, words, or links** into a QR code and save it as an image.

The main goal of this project was to learn **GUI development with Tkinter** and understand how QR code generation works in Python.

---

## Features

* Convert **text, numbers, or words** into QR codes
* Simple **graphical user interface (GUI)**
* **Preview the generated QR code**
* **Save QR code as PNG image**
* Lightweight and easy to use

---

## Tech Stack

* Python
* Tkinter (GUI)
* qrcode library
* Pillow (image processing)

## Installation

Clone the repository:

```
git clone https://github.com/VINAY-MANDAL/VINAY-MANDAL-QR_CODE_GENERATOR.git
```

Move into the project folder:

```
cd VINAY-MANDAL-QR_CODE_GENERATOR
```

Install required dependencies:

```
pip install -r requirements.txt
```

---

## Run the Application

```
python main.py
```

---

## How It Works

1. Enter **text, number, word, or URL** in the input field.
2. Click **Generate QR Code**.
3. The application will generate and display the QR code.
4. Save the QR code as an image if needed.
